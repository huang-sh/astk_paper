# Temporary open-access literature bundle workflow

This branch was created to assemble the PhD Part I literature package requested in ChatGPT.
The workflow resolves the 211-item bibliography through public scholarly metadata services and
downloads only openly accessible PDF copies. It does not bypass paywalls or authentication.

The generated GitHub Actions artifact contains PDFs, a complete metadata table, and a separate
`unavailable_title_doi.csv` file for items that could not be downloaded.
